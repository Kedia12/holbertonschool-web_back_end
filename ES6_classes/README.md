# ES6 Classes

This project introduces ES6 classes in JavaScript.

## Learning Objectives

- Define a class
- Add a constructor
- Create class methods
- Use static methods
- Extend a class
- Understand metaprogramming and symbols

## Requirements

- Ubuntu 20.04 LTS
- Node.js 20.x
- npm
- Jest
- Babel
- ESLint

## Files

| File | Description |
|---|---|
| `0-classroom.js` | Defines a `ClassRoom` class with a maximum student size |
