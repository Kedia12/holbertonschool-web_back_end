# ES6 Promise

This project focuses on handling asynchronous operations in JavaScript using ES6 Promises. It covers creating promises, using `.then()`, `.catch()`, and `.finally()`, handling errors, and working with async flows in a cleaner and more structured way.

## Learning Objectives

- Understand how Promises work
- Create and return Promises
- Use `.then()`, `.catch()`, and `.finally()`
- Handle asynchronous operations
- Manage errors in async JavaScript code
