# Basic JavaScript with Node.js

This project introduces the basics of JavaScript programming using Node.js. It covers fundamental concepts such as variables, functions, conditionals, loops, objects, arrays, and modules, while learning how to run JavaScript code outside the browser with Node.js.

## Learning Objectives

- Understand JavaScript basics
- Run JavaScript files with Node.js
- Use variables, functions, and conditions
- Work with arrays and objects
- Import and export modules
- Write clean and readable JavaScript code
